How the ranking is built

  1. Implied value. Log market cap is regressed on log TVL over the 128 protocols in this snapshot that already have a token. A pre-token protocol's implied value is what the curve predicts for its TVL. TVL alone explains about a fifth of the variation — the board says so, and the error band is shown on every row.
  2. Launch odds. The snapshot's own record: how often protocols of this age and kind have launched a token. Older protocols launch more often; some categories (basis trading, RWA) launch far more often than others (risk curators, yield aggregators). Both the age rate and the category effect are shrunk toward the overall rate, because the unshrunk versions lose to a constant base rate out of sample — the shrunk odds beat it (split-half Brier 0.135 vs 0.141).
  3. Momentum tilt. The 7-day TVL change is used only as a rank — top of the ranking +20%, bottom −20% — because the field's scale is not credible: its median absolute value is 879% and its maximum is 444,800%. A protocol that is shrinking does not get to hide behind a big TVL.

Expected value = implied value × launch odds × momentum tilt. “No token recorded” means the snapshot lists no CoinGecko id and no symbol — it is not a claim that no token exists. Farm costs are rough public-network estimates, not quotes, and no plan promises an airdrop.
